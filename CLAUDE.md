## Architecture Overview

This is a **keycap customization app** for designing custom keyboard keycaps that can be printed on sticker paper. Users create keycaps with icons, colors, and text, then export to PDF/PNG for printing.

### Tech Stack
- React 19 + TypeScript + Vite
- TailwindCSS v4 (via `@tailwindcss/vite` plugin)
- Zustand for state management (with localStorage persistence)
- Lucide React for icon library
- jsPDF for PDF export
- react-colorful for RGBA color picker
- react-dropzone for custom icon upload

### Key Data Flow

**State Management** (`src/store/keycapStore.ts`):
- Single Zustand store holds all app state: keycaps array, pageSettings, exportSettings, layout
- `recalculateLayout()` is called after any keycap/setting change to recompute bin-packing positions
- State is persisted to localStorage with the `persist` middleware

**Layout Algorithm** (`src/utils/binPacking.ts`):
- MAXRECTS-BSSF bin-packing algorithm arranges keycaps optimally on A4 page
- Keycaps that don't fit get x=-1, y=-1 and are shown in overflow section

**Export Pipeline** (`src/utils/pdfExport.ts`, `src/utils/imageExport.ts`):
- Both exports convert Lucide icons to SVG strings via `renderToStaticMarkup`
- SVGs are rendered to canvas then to PNG for embedding (jsPDF doesn't support SVG directly)
- Custom SVG icons have `currentColor` replaced with actual icon color before rendering
- Placeholders (`isPlaceholder: true`) take up layout space but are skipped during export

### Key Concepts

**Dimensions**: All measurements stored in millimeters. Conversions in `src/utils/dimensions.ts`:
- Screen display: 96 DPI
- Print export: 300 DPI
- A4 page: 210mm × 297mm

**Icon Types** (`IconConfig`):
- `lucide`: Built-in icons from Lucide library
- `custom`: User-uploaded SVG/PNG/JPG stored as base64 data URL
- `none`: No icon

**Custom SVG Color Support**:
- On upload, hardcoded colors in SVGs are converted to `currentColor` (`src/utils/iconUtils.ts`)
- This allows the icon color picker to work with uploaded SVGs
- PNG/JPG images cannot have their color changed

### Component Structure

```
App.tsx
├── Header.tsx          # Title + keyboard shortcuts info
├── Sidebar.tsx         # Tabs: Keycaps | Settings | Export
│   ├── KeycapList.tsx    # Add keycap/placeholder buttons + list
│   ├── KeycapEditor.tsx  # Edit selected keycap (size, icon, colors, text)
│   ├── PageSettings.tsx  # Margins, spacing, corner radius, default colors
│   └── ExportPanel.tsx   # PDF/PNG export buttons
└── Canvas.tsx          # A4 preview with positioned keycaps + overflow section
```

### Keyboard Shortcuts
- `Ctrl/Cmd + A`: Add new keycap
- `Delete/Backspace`: Delete selected keycap
- `Ctrl/Cmd + D`: Duplicate selected keycap
